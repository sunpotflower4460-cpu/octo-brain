## 1. 取得する情報

OctoBrain(以下「本アプリ」)は、アカウント登録なしで利用できます。本アプリが取り扱う情報は次のとおりです。

- **入力テキスト**: 分析のために入力された文章と、会話を続けるための短い要約(300字以内)です。回答を生成するため、外部の大規模言語モデル(LLM)API に送信します(第2項)。提供者のサーバーには保存しません。
- **端末内データ**: 会話履歴・下書き・設定は、**ご利用の端末内にのみ保存**します。
- **利用量の識別子**: 連打防止と月間利用回数の管理のため、端末で生成したランダムな識別子(clientId)を使います。氏名・メールアドレスなどとは結びつきません。
- **接続元IPアドレス**: 大量アクセスによる不正利用を防ぐため、1日あたりの利用回数の集計に使います。集計値は2日で自動的に消去します。
- **検索語の一時保存**: ウェブ検索を使った場合、同じ検索を繰り返さないため、検索語と検索結果を1日だけ保存します(入力テキストそのものは含みません。第2項 2-2)。
- **コスト・利用量ログ**: 品質と原価の監視のため、モデル呼び出しの**トークン数・概算コスト・処理時間**を記録します(**入力・出力の本文は含みません**)。90日で自動的に消去します。

本アプリは広告SDKや解析SDKを使わず、**トラッキングを行いません**。

## 2. 外部送信先

### 2-1. 回答の生成(LLM プロバイダー)

回答を生成するため、入力テキストと会話要約を次の事業者の API に送信します。

通常は OpenAI を使います。混雑や障害で応答できないときに限り、同じ内容を次のいずれかの事業者へ送って回答を作ることがあります(Groq → さくらインターネット → DeepSeek の順)。

- **OpenAI**(OpenAI, L.L.C. / アメリカ合衆国)
  - 送信したデータは OpenAI 社のサーバーで処理されます。同社の API の方針により、API で送信されたデータは既定ではモデルの学習に使われません。
- **Groq**(Groq, Inc. / アメリカ合衆国)
  - 混雑・障害時の切り替え先です。送信したデータは Groq 社のサーバーで処理されます。
- **さくらインターネット**(さくらインターネット株式会社 / 日本)
  - 混雑・障害時の切り替え先(さくらのAI Engine)です。送信したデータは国内のサーバーで処理されます。
- **DeepSeek**(Hangzhou DeepSeek Artificial Intelligence Co., Ltd. / 中華人民共和国)
  - 送信したデータは、中華人民共和国内にある DeepSeek 社のサーバーで処理されます。取り扱いは、同社の API(オープンプラットフォーム)の利用規約に従います。
- **Cloudflare, Inc.**(米国)
  - 本アプリのサーバー(API の中継)の運用基盤です。

### 2-2. 事実の確認のための検索

回答に関わる法律・制度・用語・最新の情報を確かめるため、次の公開の情報源に**検索語**を送ることがあります。検索語は、入力テキストをもとに言語モデルが作る一般的な言葉(例:「労働基準法 第20条」「育児休業」)で、**入力テキストそのものは送りません**。名前・会社名・学校名などの個人を特定できる情報を検索語に含めないよう制御しています。

- **e-Gov 法令API**(デジタル庁 / 日本): 法令の条文の取得
- **Wikipedia**(Wikimedia Foundation, Inc. / アメリカ合衆国): 用語・制度の概要の取得
- **Tavily**(Tavily Inc. / アメリカ合衆国): 最新の情報のウェブ検索(有効にしている場合のみ)

本アプリは初回の送信前に、上記の外部送信について同意をいただきます。同意はアプリの「設定」からいつでも取り消せます。取り消した後は、再び同意するまで送信しません。

**氏名・住所・電話番号・健康状態など、他人に知られたくない情報は入力しないでください。**

## 3. 利用目的

- 入力に対する分析回答の生成
- 不正・過負荷の防止(連打防止・利用回数の上限)
- 品質・原価・障害の監視と改善

## 4. 第三者提供

法令に基づく場合を除き、入力テキストを第三者に販売・提供しません。LLM プロバイダーへの送信は、回答生成のための処理の委託です。検索先(第2項 2-2)には入力テキストを送らず、一般的な検索語だけを送ります。

## 5. データの保存と削除

- 会話・設定は端末内にあります。アプリの「設定 → ローカル会話データを削除」、またはアプリの削除で消去できます。
- サーバー側のコスト・利用量ログは本文を含まず、90日で自動的に消去します。IPアドレスの集計値は2日で消去します。
